# Проверка страницы

## 1. Проверка обрыва загрузки данных (Network)
1. Открой DevTools и перейди во вкладку Network.
2. Найди запросы за данными (в частности .json), нажми правой кнопкой мыши и выбери Block Request, затем Block request URL.
3. Обнови страницу через Ctrl + R.
4. Оцени результат:
   1. Провал: на странице пустое место (карточки и текст пропали) и нет сообщения об ошибке.
   2. Отлично: появилось сообщение об ошибке загрузки.
(После проверки не забудь разблокировать запрос).

Claude по коду: Claude проверяет код и указывает на ошибки в коде (отсутствие try/catch и response.ok в projects.js)
Человек в браузере: Ручная проверка (обновление страницы через сочетание клавиш Ctrl + R, открыть вкладку Network, блокировка Block Request и Block Request URL)

## 2. Проверка мобильного вида
1. В DevTools включи мобильный режим через Ctrl + Shift + M и выставь ширину экрана 320px.
2. Проверь страницу по четырем условиям:
   1. Ничего не вылезает за ширину экрана телефона, не липнет к краям и не ужимается.
   2. Нет горизонтальной прокрутки.
   3. Текст читается хорошо без увеличения.
   4. По кнопкам можно нажать пальцем и не промахнуться.
3. Оцени результат:
   1. Провал: не выполнено хотя бы одно условие.
   2. Отлично: все четыре условия выполнены.

Claude по коду: Может проверить только код (viewport в projects.html и фиксированные ширины в style.css, которые не влезут на 320px)
Человек в браузере: Проверка на сайте идет вручную, открыть DevTools, сочетанием клавиш включить мобильную версию

## 3. Проверка ошибок в консоли (Console)
1. Перейди во вкладку Console в DevTools и прочитай все ошибки.
2. Оцени результат:
   1. Провал: есть красные ошибки.
   2. Игнорировать: желтые предупреждения про Permissions Policy.
   3. Записать в находки: любые другие желтые предупреждения (нужно разобраться, откуда они, и записать).

Claude по коду: Claude не видит консоль
Человек в браузере: Открыть DevTools, открыть вкладку Console, проверить ошибки

## 4. Проверка ссылок
1. Нажми на все ссылки на странице.
2. Оцени результат:
   1. Провал: ссылки не нажимаются, недоступны или ведут в никуда и на несуществующую страницу.
   2. Отлично: все ссылки нажимаются и ведут туда, куда указано.

Claude по коду: Проверка ссылок по файлам (проверь, что файл существует рядом)
Человек в браузере: Проверка внешних ссылок (зайти на сайт, нажать на каждую ссылку вручную проверив их на работоспособность)
